# Privacy and support data — demo guidance
Fictional store documentation. Do not input live personal data into the portfolio demo.
To request a copy of your account data, open Account > Privacy > Export data. You may need to verify your identity.
To request account removal, use Account > Privacy > Delete account. Some billing records may be retained where legally required.
Support representatives will never request your full password, PIN, complete payment card number or one-time security code.
This demo assistant only stores topic, result status, response time and query length for analytics. It does not store raw chat messages.
