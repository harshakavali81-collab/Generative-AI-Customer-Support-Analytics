# Returns and refunds — demo policy
This is fictional sample documentation for a portfolio project. It does not represent a real merchant.
Customers can request a return within 30 days of the delivery date. Items must be unused and in original packaging.
To start a return, sign in to the demo account and select Orders, then Request return. A support agent reviews the request.
Once a return is received and approved, refunds are sent to the original payment method within 5 to 7 business days.
Shipping fees are not refundable unless the item arrived damaged or the merchant made an error.
Items purchased as final sale cannot be returned unless required by applicable law.
