# Changelog

## 1.1.0 — 2026-10-28

- Source-linked extractive support answers over six fictional policies.
- Offline sparse TF-IDF retrieval, deterministic chunks and curated evaluation.
- FastAPI chat, source catalog and response analytics routes.
- React chat and data visualization interface.
- Anonymous helpful/unhelpful feedback with single-vote request IDs.
- Aggregate CSV export and 30-day default telemetry retention.
- Basic input data checks, demo rate limiting, production fail-closed token gates and security headers.
- Ten original educational architecture/analytics illustrations.
- Source CI, local smoke tests, reproducible retrieval microbenchmark and Docker Compose.
- Standalone browser-only static showcase mirrored into the portfolio repository.
- Deployment, threat model, data dictionary, operations and API documentation.
- Manual Pages workflow after GitHub permission restriction blocked first-time site activation.

This release is an educational portfolio prototype, **not** a certified production service.
